# Midia2You - Landing Page

Lnading Page moderno e responsivo para a Midia2You, equipe criativa e estratégica especializada em gestão de redes sociais, produção de conteúdo e cobertura de eventos em tempo real.

🌐 **[Ver Site Online](https://www.midia2you.com.br/)**

## 🎯 Visão Geral do Projeto

A Midia2You é uma Landing Page profissional desenvolvido para apresentar serviços de marketing digital e gestão de redes sociais. O site apresenta um design elegante e limpo, com elementos gráficos customizados, carrosséis interativos e layout totalmente responsivo que funciona perfeitamente em todos os dispositivos.

## ✨ Funcionalidades

- **Design Responsivo**: Layout totalmente responsivo que se adapta a todos os tamanhos de tela
- **UI/UX Moderna**: Design elegante com elementos SVG customizados e paleta harmoniosa
- **Carrosséis Interativos**: Galerias dinâmicas de portfólio com navegação suave
- **Modal de Vídeos**: Player integrado para apresentação de conteúdo multimídia
- **Integração WhatsApp/Instagram**: Botões de contato direto para comunicação instantânea
- **Menu Responsivo**: Navegação hambúrguer para dispositivos móveis
- **Animações Suaves**: Transições e efeitos que melhoram a experiência do usuário

## 🛠️ Tecnologias Utilizadas

- **HTML5**: Estrutura semântica e moderna
- **CSS3**: Estilização modular com Grid, Flexbox e animações
- **JavaScript Vanilla**: Funcionalidades interativas sem dependências
- **Google Fonts**: Tipografia personalizada (Montserrat)
- **Fonte Customizada**: Brown Sugar para elementos de destaque
- **SVG**: Elementos gráficos otimizados e escaláveis

## 🚀 Como Começar

### Pré-requisitos

- Um navegador web moderno
- Conhecimento básico de HTML, CSS e JavaScript (para modificações)

### Instalação

1. Clone o repositório:
```bash
git clone https://github.com/TheLC7/midia2you.git
```

2. Navegue até o diretório do projeto:
```bash
cd midia2you
```

3. Abra `index.html` no seu navegador preferido ou configure um servidor local:
```bash
# Usando Python 3
python -m http.server 8000

# Usando Node.js (se você tiver o http-server instalado)
http-server
```

4. Visite `http://localhost:8000` no seu navegador
